# Blackjack-AI
This repository has all the code from my perfect blackjack AI video on my youtube channel.\
\
basicstrat.py - AI that runs on basic strategy\
blackjack.py - Simulation that the AIs play in\
graph.py - Helper file to graph wins and profit\
hilo.py - AI that runs on basic strategy using high-low card counting for betting\
perfect.py - AI that simulates all possible potential games to play and bet\
pixelfont.ttf - Font used in the simulation\
cardback.png - Image for back of cards\
deck.png - Image for deck\
cards - Folder containing all the images for the cards\
